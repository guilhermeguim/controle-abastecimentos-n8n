## Summary

- Type: PATCH.
- Scope: public documentation and repository hygiene.
- Workflow changes: none.

## Goal

Improve the public presentation of the project after the initial release by making the README clearer, English-first, and closer to the style used by related personal automation repositories.

## Main Changes

- Rewrote the README in English.
- Clarified that the workflow tracks car fuel fill-ups.
- Documented that `HB20` is the default vehicle rule.
- Added stack badges for n8n, Telegram, Groq, SQLite, Docker, GCP, Caddy, and MIT.
- Expanded the workflow logic, pending-state model, AI boundaries, and hosting model.
- Renamed `docs/versionamento.md` to `docs/versioning.md`.
- Removed internal contribution and assistant instruction files from the public repository.

## Workflow And Database Impact

There is no workflow logic change in this release.

The sanitized workflow remains at 24 nodes, and the SQLite schema remains unchanged.

## Rollback
