# Release v1.0.0

## Closing Date

2026-07-20

## Comparison Base

First public release of the project.

## Summary

- Type: initial MAJOR release.
- Scope: publish the versionable base of the n8n workflow.
- Original workflow inspected: `Abastecimentos.json`.
- Public workflow: `workflow/abastecimentos.sanitized.json`.
- Nodes in the original export: 24.
- Nodes in the sanitized export: 24.

## Goal

Publish the first documented version of the personal car fuel tracking workflow for n8n without exposing credentials, tokens, the real database, or instance metadata.

## Closing Procedures

- Original export identified and kept outside Git.
- Sanitized JSON generated from the original export.
- Credentials, webhook IDs, and instance metadata removed.
- Minimal SQLite schema documented.
- Versioning process documented.
- Local validations executed before publication.

## Main Deliverables

- Fuel fill-up registration from Telegram messages.
- Continuation of incomplete entries through state in `abastecimentos_pendentes`.
- Correction, confirmation, and cancellation of pending entries.
- Final persistence in `abastecimentos`.
- Natural-language queries with an agent limited to a read-only SQLite tool.
- Initial import, safety, and maintenance documentation.

## Database Changes And Migration

This release includes only the initial schema in `database/schema.sql`.

There is no real data, incremental migration, or sample data load.

## Compatibility

- n8n Community Edition.
- Community node `n8n-nodes-sqlite3`.
- Telegram Bot configured in n8n.
- Groq credential configured in n8n.
- Model `openai/gpt-oss-120b`.
- SQLite with `abastecimentos` and `abastecimentos_pendentes`.

## Recommended Deployment Procedure

1. Install the SQLite community node in n8n.
2. Create the private SQLite database.
3. Apply `database/schema.sql`.
4. Import `workflow/abastecimentos.sanitized.json`.
5. Configure Telegram, Groq, and SQLite credentials.
6. Review environment-dependent parameters.
7. Test the workflow in n8n before activation.

## Post-Deploy Smoke Test

- Send a new fuel fill-up message through Telegram.
- Confirm the missing-field prompt when the message is incomplete.
- Confirm a complete entry.
- Ask for the last fuel fill-up in natural language.
- Cancel a test pending entry.

## Rollback

Return to the previous stable tag and manually import the corresponding sanitized JSON.

Credentials, the real database, execution history, and Docker volumes must be recovered from a separate private backup.
